# Network Security Assignment 5

---

## 1. What is the main advantage of a stateful firewall over a stateless firewall?

**Multiple-Choice (12.5 Points)**

A. It blocks all malicious traffic entering the network.

B. It encrypts packets during network communication.

C. It inspects only the payload without analyzing packet headers.

D. It tracks connection state and active communication sessions.

**Right Answer:** D

---

## 2. What is the major weakness of packet filtering?

**Multiple-Choice (12.5 Points)**

A. It requires encrypted traffic before filtering can be applied.

B. It cannot inspect packet header information during filtering.

C. It processes network traffic too slowly under heavy load.

D. It cannot understand connection state or communication context.

**Right Answer:** D

---

## 3. What does the term “stateless” mean in the context of IP communication?

**Multiple-Choice (12.5 Points)**

A. Packets are protected using encryption during transmission.

B. Packets in one session must follow the same routing path during transmission.

C. Packets are processed independently without storing connection history.

D. Routers keep session information for every active communication.

**Right Answer:** C

---

## 4. In an ICMP Redirect attack, what is the primary objective of the attacker?

**Multiple-Choice (12.5 Points)**

A. To reroute victim traffic through an attacker-controlled gateway.

B. To disable routing tables within network infrastructure devices.

C. To reduce network performance by fragmenting large packets.

D. To disrupt encrypted communication between network hosts.

**Right Answer:** A

---

## 5. Why is the Internet Protocol (IP) inherently vulnerable to spoofing attacks?

**Multiple-Choice (12.5 Points)**

A. It lacks a built-in method to verify source IP authenticity.

B. It automatically rejects traffic from unknown network systems.

C. It requires encryption for all transmitted packet payloads.

D. It uses connection-oriented communication with handshake validation.

**Right Answer:** A

---

## 6. An attacker positioned between two communicating parties who can intercept, read, and modify packets in real-time is known as a(n)

**Multiple-Choice (12.5 Points)**

A. DoS attacker

B. Passive listener

C. On-path attacker

D. Off-path attacker

**Right Answer:** C

---

## 7. Why can fragmented packets create security risks for firewalls and intrusion detection systems (IDS)?

**Multiple-Choice (12.5 Points)**

A. Fragmentation automatically encrypts transport-layer header information.

B. Security devices may inspect fragments without seeing the complete packet.

C. Fragmented packets prevent routers from forwarding network traffic.

D. Routers are unable to process fragmented packets correctly.

**Right Answer:** B

---

## 8. What is the main function of a Virtual Private Network (VPN)?

**Multiple-Choice (12.5 Points)**

A. To reduce communication latency between remote systems

B. To create a secure tunnel across untrusted networks

C. To block all malicious incoming and outgoing network traffic

D. To replace IPsec in all network security deployments

**Right Answer:** B
